# Moonforged Build Pieces (Revamped)

A standalone Moonforged building set featuring carved and runed timber pieces, arches, doors, railings, floors, walls, trellises, window frames, and stained-glass windows.

Designed to expand Valheim building while keeping a consistent Viking-inspired Moonforged style.

Includes Valheim 1.0 build-menu sorting and a configurable Moonforged Hammer category.

**Windows version included.**

If you need a **Vulkan or Mac compatible version**, please contact me on [Discord](https://discord.gg/xtfpFnWmm).

I keep those builds separate because including all platform versions in the main package would make the download unnecessarily large, while only a small number of users need them.

---

Moonforged Build Pieces is now focused entirely on structural and architectural building pieces.

## The original Moonforged Build Pieces collection has been separated into three standalone mods:

- **Moonforged Build Pieces** – Carved and runed building pieces, doors, arches, beams, walls, stairs, railings, frames, and stained-glass windows.
- **Moonforged Lights and Decor** – Rugs, furniture, lamps, porcelain sets, benches, cannons, and other decorative pieces.
- **Moonforged Banner Collection** – Biome, boss, vendor, Hildir quest, miniboss, and Deep North banners.

# 🔨 Valheim 1.0 Build Menu Support

Moonforged Build Pieces supports Valheim's new build-menu sorting system.

All pieces remain available under the dedicated:

**Moonforged Build Pieces**

category.

They are also tagged with Valheim's **Building** usage category, so they can appear when players use the normal Valheim build-menu sorting system.

---

## 🔧 Custom Hammer Category

The Moonforged Hammer category can be changed through the configuration file.

Players can enter another category name to move all Moonforged Build Pieces into a custom Hammer/build-menu category.

For example:

```ini
BuildingCategory = Moonforged Building
```

The default category is:

**Moonforged Build Pieces**

# 🔨 How to Install

## 1. Install the Required Dependencies

- [BepInEx Pack](https://valheim.thunderstore.io/package/denikson/BepInExPack_Valheim/)
- [Jötunn](https://valheim.thunderstore.io/package/ValheimModding/Jotunn/)

## 2. Install Moonforged Build Pieces

If installing manually:

- Download the mod.
- Place the `.dll` inside:

`BepInEx/plugins/MoonforgedBuildPieces/`

You may also place the mod inside another folder under `BepInEx/plugins/`.

## 3. Launch Valheim

The new pieces will appear in the Hammer build menu under:

**Moonforged Build Pieces**

They will also appear through Valheim's **Building** build-menu sorting tag.
